KASHIF AI — Project Plan
خطة بناء مشروع كاشف الزيف والنصب
Version: 0.1
Initial Market: Egypt
Initial Platform: Android-friendly PWA
First Module: KASHIF TEXT
Budget: Zero paid subscriptions and APIs.
1. Project Vision
KASHIF AI is an Egyptian digital safety project designed to help people identify warning signs of online fraud, suspicious messages, and digital deception.
Its mission is:
تحقق قبل ما تصدق — TRUST BEFORE YOU ACT
The first objective is to build a practical Arabic-first tool that helps users assess suspicious messages before taking action.
2. First Development Module: KASHIF TEXT
The first version will analyze text messages in Arabic, Egyptian colloquial Arabic, and English.
It will look for warning signs such as:
Urgent requests for money.
Threats involving bank accounts or services.
Fake prizes and unexpected rewards.
Requests for passwords or one-time verification codes.
Suspicious links and misleading wording.
Impersonation indicators.
The application will explain every warning sign it identifies.
3. First Version Features
Simple Arabic interface suitable for Android phones.
Text input and paste functionality.
Explainable text-analysis engine.
Risk indicator: Low, Caution, or High.
Explanation of detected warning signs.
Practical safety recommendations.
Clear and reset functions.
The application must not present its assessment as a definitive judgment.
4. Technical Strategy
The project will use:
HTML
CSS
JavaScript
Progressive Web App (PWA)
GitHub for source-code management.
GitHub Pages for free static hosting, subject to its usage limits.
Initial analysis will run in the browser wherever practical.
No paid APIs, subscriptions, or external AI services will be used in the first phase.
5. Development Device
Current development device:
OPPO Reno4 (CPH2113)
Android 12
8 GB physical RAM
128 GB storage
The first application must be lightweight and usable on this device.
Heavy AI models, audio analysis, and video analysis are postponed until later stages.
6. Future Development Modules
KASHIF IMAGE
Image text extraction.
Suspicious content analysis.
Image authenticity research.
KASHIF VOICE
Speech-to-text.
Suspicious speech analysis.
Independent audio authenticity checks.
KASHIF VIDEO
Video frame analysis.
Audio and visual consistency checks.
Deepfake research and testing.
KASHIF TRUST TRACE
Combine evidence from multiple sources.
Explain findings and contradictions.
Provide safe next steps.
These modules are planned, not yet implemented.
7. Privacy and Security
Do not collect unnecessary personal information.
Do not transmit submitted messages to external services in the first version.
Never request passwords, PINs, or one-time passwords.
Do not automatically open suspicious links.
Protect users' private data.
Review open-source licenses before commercial use.
8. Testing and Quality Standards
Before accepting the first version, test:
Normal messages.
Known scam-pattern messages.
Egyptian colloquial Arabic.
English messages.
Mixed Arabic and English.
Suspicious links.
False positives and false negatives.
Performance on the target Android phone.
Privacy and data handling.
No accuracy percentage will be advertised without documented testing on a defined dataset.
